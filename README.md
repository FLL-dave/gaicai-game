# 韭菜大冒险 · 智慧版

一个把耶鲁大学《金融市场》公开课（罗伯特·希勒主讲，2013 年诺贝尔经济学奖得主）变成可玩游戏的打工人理财生存模拟器。

课程来源：B 站 BV1zm411k7ZP（耶鲁《金融市场》，24 讲 + 访谈）

## 怎么玩

双击打开 `韭菜大冒险.html`（单文件自包含，无需联网）：

1. 建议先点「先看智慧短片（90 秒）」看一遍原创短片，再点「金融关系图谱」理清六条核心关系；
2. 开始打工：经历 21 个财年（24–45 岁），面对牛市、熊市、泡沫、崩盘和结婚生娃买房等人生事件；
3. 每年解锁一张「希勒智慧卡」：直觉故事 + 核心公式 + 怎么用 + 希勒原话；
4. 结算人生后，自动生成「理财体检报告」：逐条点评你的每一次操作，并给出一条公式级结论。

目标：45 岁时净资产达到 300 万，实现「财务自由 · 巴菲特中国分巴」。

## 智慧版新特性（v2）

- **希勒智慧卡**：15 张知识卡升级为「直觉 + 公式 + 运用 + 原话」四层结构（CAPM、分散化、损失厌恶 λ≈2.25、费雪方程……）
- **金融关系图谱**：风险⇄收益、分散⇄波动、情绪⇄泡沫、杠杆⇄脆弱、通胀⇄现金、流动性⇄危机
- **理财体检报告**：逐次决策回放（神操作/骚操作/中性）+ 公式级总结论
- **原创短片** `assets/wisdom.mp4`：90 秒智慧短片（画面/旁白/配乐均为 AI 原创）
- **原创配乐** `assets/music.mp3`：游戏内可开关的背景音乐

## 数值设计（单一数据源）

- 规则集：`YALE_FIN_R1_2026`；21 个财年；单局约 5–8 分钟
- 目标：净资产 ≥ 300 万；起薪 8000 元/月（13 薪）、月支出 4500、通胀 3%、工资年增长 5%±3%
- 市场脚本 21 年：flat/bull/bull/bear/flat/bear/flat/bull/bubble/crash/flat/bear/flat/bull/bull/bear/flat/bull/flat/bull/flat
- 平衡验证（`_sim.py`，3000 局/策略，口径 ≥300 万）：稳健策略达成率 98.2%、保守 35.2%、随机 49.9%、赌徒 0.1%
